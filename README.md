# 🔐 Form Validation

A responsive Login and Signup Form Validation project built using **HTML, CSS, and JavaScript**.

This project was developed as part of **Level 1 – Task 3** of my Web Development Internship at **RaushByte Technologies**.

---

## 📌 Project Overview

This project demonstrates how JavaScript can be used to validate user input in Login and Signup forms.

The application provides separate Login and Signup forms with client-side validation for:

- Email addresses
- Password length
- Required fields
- Confirm password matching
- Error messages
- Successful form submission

The project focuses on creating a simple, user-friendly, and responsive form validation experience.

---

## 🎯 Objectives

The main objectives of this project are:

- Learn client-side form validation using JavaScript.
- Validate email addresses using a regular expression.
- Check password length.
- Display meaningful error messages.
- Validate password confirmation during signup.
- Prevent form submission when the entered information is invalid.
- Create a clean and responsive user interface.

---

## ✨ Features

### 🔑 Login Form

The Login form includes:

- Email validation
- Password validation
- Empty field checking
- Minimum 8-character password requirement
- Error messages for invalid input
- Success message after valid submission

### 📝 Signup Form

The Signup form includes:

- Full name validation
- Email validation
- Password validation
- Minimum 8-character password requirement
- Confirm password validation
- Password matching validation
- Error messages for invalid input
- Success message after valid submission

### 🔄 Login / Signup Switching

Users can switch between the Login and Signup forms using the tabs provided at the top of the form.

### 📱 Responsive Design

The interface is designed to work across different screen sizes, including:

- Desktop
- Tablet
- Mobile devices

## 🛠️ Technologies Used

- HTML5 : Structure of the forms
- CSS3  : Styling, layout, colors, and responsiveness
